## 功能介绍

覆盖编程、办公、生活各类在线工具，全部免费使用，无需注册。

### 🔧 开发工具
- JSON 格式化 / 压缩 / 校验
- Base64 编解码
- URL 编码解码
- 时间戳转换
- MD5 / SHA 加密
- 颜色转换（HEX、RGB、HSL）
- Cookie 转 JSON / HTTP 请求头转 JSON

### 📝 文本工具
- 大小写转换
- 繁简体转换
- 文本去重 / 排序 / 统计
- UUID 生成器
- 字符频率统计

### 🏥 生理健康
- BMI 计算器
- 喝水提醒
- 睡眠计算器

### 🎮 娱乐工具
- 星座运势
- 笑话生成器
- 实时热搜
- 天气查询
- 历史上的今天

### 💰 金融工具
- 房贷计算器
- 个税计算器

## 技术栈

- [Nuxt 3](https://nuxt.com) — Vue 全栈框架
- [Tailwind CSS](https://tailwindcss.com) — 样式框架
- [Cloudflare Pages](https://pages.cloudflare.com) — 部署平台

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建
npm run build
```
